# 3D Model Studio

**Three.js だけ**で作った、ブラウザ上で 3D モデルを作れるスタジオアプリです。
立方体・球・円柱などの部品（プリミティブ）を置いて、動かして、組み合わせてモデルを作ります。

UI フレームワークは使わず、実行時の依存は `three` のみ（Vite は開発サーバーとビルドだけに使用）。

## 起動方法

```bash
npm install
npm run dev      # http://localhost:5173 で開く
```

静的ファイルとしてビルドする場合:

```bash
npm run build    # dist/ に出力（相対パスなので GitHub Pages 等にそのまま置ける）
npm run preview
```

## GitHub Pages で公開する

`.github/workflows/deploy.yml` により、`main` ブランチに push されるたびに自動でビルドして GitHub Pages に公開されます。

最初の 1 回だけ、リポジトリの設定が必要です。

1. GitHub のリポジトリページで **Settings → Pages** を開く
2. **Build and deployment → Source** を **GitHub Actions** にする
3. `main` に push（または **Actions** タブから「Deploy to GitHub Pages」を手動実行）

公開 URL: `https://<ユーザー名>.github.io/3d_model_studio/`

## PWA（アプリとしてインストール）

GitHub Pages で公開したページは PWA に対応しています。

- **インストール**: Chrome / Edge ではツールバー右端の「⬇ インストール」ボタン（またはアドレスバーのインストールアイコン）から。iPhone / iPad は Safari の共有メニュー →「ホーム画面に追加」。
- **オフライン**: 一度開けば、ネットがなくても起動・編集・保存・書き出しができます（ツールバーに「オフライン」と表示）。
- **更新**: 新しい版を公開すると、次に開いたときに「新しいバージョンがあります」と表示され、「更新する」で切り替わります。作業内容は自動保存されているので消えません。

Service Worker（`dist/sw.js`）はビルド時に `vite.config.js` のプラグインが `src/sw.js` をもとに生成し、ビルド成果物すべてを事前キャッシュします。
そのため `npm run dev` では登録されません。動作確認は `npm run build && npm run preview` で行ってください。

## 遊ぶモード（作ったモデルを動かす）

ツールバーの「▶ 遊ぶ」で、作ったモデルを操作して今の世界を歩き回れます。「✕ 作る画面へ」（または Esc）で戻ると、モデルは元のままです。

| 操作 | PC | スマホ・タブレット |
| --- | --- | --- |
| 移動 | WASD / 矢印キー | 左下のスティック |
| 走る | Shift を押しながら | 「走る」ボタン（ON/OFF） |
| ジャンプ | Space | 「ジャンプ」ボタン |
| 曲がる | W を押しながら A / D | スティックを斜め前へ倒す |
| 見回す・ズーム | ドラッグ・ホイール | 画面をドラッグ・ピンチ |

- **歩きながら曲がる**: 歩いている間、カメラはゆっくりキャラクターの後ろへ回り込みます。前＋左右を押し続けるとその方向へ曲がり続けます。後ろ向きに歩くときや、カメラを自分で回した直後は、カメラは回り込みません

- **動くしくみ**: 部品の「役割」（足・腕・頭・しっぽ・羽・車輪）から関節を自動で作ります。足は交互に振られ、腕は逆に振られ、頭はうなずき、しっぽは揺れ、羽ははばたき、車輪は回ります。役割のない部品は「体」として弾んだり前に傾いたりします。足も車輪もないモデルは、ぴょこぴょこ跳ねて進みます
- **役割の付け方**: 部品の名前から自動で推測します（「右脚」「腕」「頭」「しっぽ」「タイヤ」など）。違うときはプロパティの「動きの役割」で選び直します。グループに付けた役割は中の部品にも効きます。左右・前後は位置から自動で判定します
- **正面の向き**: モデルの正面は手前（青い矢印の +Z 方向）が前です。後ろ向きや横向きに歩くときは、遊んでいる間に「↻ 正面の向き」で 90° ずつ回せます（作品に保存されます）
- **動かすもの**: 一番上のグループ（または部品）を 1 つ選んでから「▶ 遊ぶ」を押すと、それだけが動き、ほかの部品は乗ったりぶつかったりできる置物になります。何も選んでいなければモデル全体が動きます
- **世界ごとの地面と重力**: 丘や砂丘の起伏に沿って歩けます。月では高く長く跳べ、水中や宇宙ではふわっと跳びます。雲の上の浮島では、島の端から落ちると最初の場所に戻ります

## 作品（最大 5 件）

作ったモデルは「作品」としてブラウザに自動保存され、最大 5 件まで並べて置いておけます。ファイルに書き出して消さなくても、次のモデル作りに入れます。

- ツールバーの「📁 作品名 ▾」で一覧を開き、見本画像付きの作品から選んで切り替えます（スマホ・タブレットも同じ場所）
- 「＋ 新しい作品」（または「新規」）で空の作品を作ります。今の作品はそのまま残ります
- 各作品の ✎ で名前変更、⧉ で複製、🗑 で削除
- 5 件あるときは新しく作れないので、不要な作品を削除します（残したいものは先に「保存」や「書き出し」でファイルへ）
- 「開く」で読み込んだファイルや「サンプル」も新しい作品として開きます。5 件あるときは、今の作品を置き換えてよいか確認します
- 作品ごとに世界（背景）も記録されます。保存・書き出しのファイル名には作品名が使われます

作品はこのブラウザ（端末）の中だけに保存されます。別の端末に移すときや、ブラウザのデータを消す前は「保存」でファイルに残してください。

## 世界（背景）

PC はツールバーの「🌍」、スマホ・タブレットは下のタブの「世界」から、14 種類の世界に切り替えられます。
空・地面・光・霧・動き（雲、波、雪、泡、星のまたたき など）がまとめて変わります。

| 分類 | 世界 |
| --- | --- |
| 基本 | 夜のスタジオ / 撮影ブース / 設計図 |
| 自然 | 草原と青空 / 夕焼けの海辺 / 雪原 / 砂漠 / 森の中 / 水中 |
| 空想 | 星空の夜 / 宇宙 / 月面 / ネオン街 / 雲の上の浮島 |

- 光も世界に合わせて変わります（夕焼けならオレンジに、夜なら暗く）。部品の色をそのまま見たいときは「作業用ライト」を ON にします。
- 選んだ世界は保存ファイルと自動保存に記録され、開き直すと同じ世界に戻ります。
- 画像（PNG）の書き出しには背景も写ります。GLB / OBJ / STL などの 3D データにはモデルだけが入ります。
- 空・地面・雲・星・水などはすべてコードで生成しているので、画像ファイルの読み込みはなく、オフラインでも使えます。

世界を増やすときは `src/worlds/` に定義を追加し、`src/worlds/index.js` の一覧に並べます（返す値の形は `src/worlds/basic.js` の先頭のコメントを参照）。

## グループ化のしかた

複数の部品を 1 つにまとめると、まとめて動かしたり回したりできます。

1. まとめたい部品のどれか 1 つを選ぶ
2. 「グループ化」を押す（PC はツールバー、スマホ・タブレットは下に出るボタン）
3. 画面上に「部品を選んでください」と出るので、一緒にまとめたい部品を順に選ぶ（もう一度選ぶと解除）
   - スマホ・タブレットでは、部品を**長押し**しても選択に追加できます
4. 「グループ化する」を押す

PC なら Shift+クリックで 2 つ以上選んでから Ctrl+G でも同じです。グループの中の部品だけを動かしたいときはダブルクリック（ダブルタップ）、グループを元に戻すときは「解除」を使います。

## 対応端末

| 端末 | 画面構成 |
| --- | --- |
| PC | 上にツールバー、左に部品・一覧、右にプロパティの 3 列 |
| iPad などのタブレット（iPad Pro 横向きまで） | 3D 画面を全面に使い、下のタブ（部品 / 一覧 / 調整 / メニュー）で左右からパネルを出す |
| iPhone などのスマホ | 下のタブでパネルを開くと、画面を上下に分けて 3D 画面を見ながら編集できる |

タッチ操作：

| 操作 | 内容 |
| --- | --- |
| 1 本指ドラッグ / 2 本指ドラッグ / ピンチ | 視点の回転 / 平行移動 / ズーム |
| タップ | 選択（グループはまとめて選択） |
| 長押し | 選択に追加（複数選択。3D 画面でも一覧でも使える） |
| ダブルタップ | グループの中の部品を直接選択 |
| 左上の「複数」 | ON の間はタップで選択を追加・解除（Shift+クリックの代わり） |
| 選択中の部品をドラッグ | 床の上をすべらせて移動（高さは変わらない） |
| ギズモの矢印をドラッグ | その方向にだけ移動（上下は緑の矢印） |
| 左上の 移動 / 回転 / 拡縮 | ギズモの切替（タッチ端末ではギズモを大きく表示） |
| 選択中に下に出るボタン | 複製・反転コピー・床に置く・グループ化・削除など |
| 一覧の ⠿ をドラッグ | グループへの出し入れ・並べ替え |
| X / Y / Z の文字を左右にドラッグ | 数値を少しずつ変更 |

iPhone / iPad で保存・書き出しをすると共有シートが開くので、「ファイルに保存」などを選んでください。

```
src/primitives.js   部品の定義（形状パラメータとジオメトリ生成）
src/serializer.js   シーン ⇔ JSON の変換、マテリアル
src/history.js      Undo / Redo（スナップショット方式）
src/sample.js       サンプルモデル（ロボットと木）
src/worlds/         世界（背景）の定義。common.js が空・星・雲・地面などの共通部品

src/style.css       スタイル

```

### 部品を増やすには

`src/primitives.js`（基本の部品）か `src/primitives-extra.js`（追加の部品）に 1 項目追加し、`src/primitives.js` の `CATEGORIES` のどれかの分類に id を並べると、パレット・プロパティパネル・保存形式すべてに反映されます。

```js
ring: {
  label: 'リング',
  icon: '◎',
  params: [
    { key: 'inner', label: '内径', min: 0, max: 5, step: 0.05, default: 0.3 },
    { key: 'outer', label: '外径', min: 0.05, max: 5, step: 0.05, default: 0.5 },
  ],
  build: (p) => new THREE.RingGeometry(p.inner, p.outer, 48),
},
```
